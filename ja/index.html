とにかく動くように設計

yt-dlpにできることすべてを、ターミナルに触れずに。

  • 1,800以上のサイト

    YouTube、Instagram、TikTok、Twitch、Twitter/X、Reddit、Facebook、Vimeo、SoundCloud、そしてyt-dlpが対応するほぼすべての場所。

  • 常に最新

    起動時にyt-dlpのアップデートを確認し、ワンクリックでアップグレード。新しいサイトやフォーマットにも対応し続けます。

  • Cookie認証

    cookies.txtを添付すれば、自分自身のログイン済みセッションを使って年齢制限・メンバー限定・非公開のコンテンツを取得できます。

  • 10言語対応

    English、Türkçe、Español、Français、Deutsch、Português、العربية、日本語、한국어、中文 — 後付けではなく最初から組み込み。

  • ライト・ダーク・システム

    OSに自動で合わせるか、自分で設定できます — すぐ上で実際に確認してみてください。

  • リアルタイム進捗

    すべてのダウンロードの正確なパーセンテージ、転送速度、状態がリアルタイムで更新されます。

  • スマートキュー

    最大3件のダウンロードを同時実行。残りは自動で順番を待ちます。

  • 消えない履歴

    ダウンロードリストは再起動しても保持されます — アプリを閉じても何も消えません。

  • ファイル操作も内蔵

    アプリを離れることなく、完了したダウンロードの名前変更、Finder/エクスプローラーでの表示、削除ができます。

もっと詳しく見る

すべての画面は同じフラットで細い罫線のシステムで構築されています — 借り物でも、ありきたりでもありません。

KeepMeTubeを入手

無料、オープンソース、アカウント不要。

macOS

macOS 11 Big Sur以降

Apple Silicon版をダウンロード Intel Mac版(.dmg)

Windows

Windows 10以降、64ビット

インストーラーをダウンロード(.exe) MSIパッケージ(.msi)

Linux

ほとんどの64ビットディストリビューション

AppImageをダウンロード .deb .rpm

macOSで「壊れている」と表示される? 実際には壊れていません — KeepMeTubeはまだAppleの公証(notarization)を受けていないため、App Store以外からのダウンロードはGatekeeperによって既定で警告されます。

アプリを右クリックして開くを選択するか、ターミナルで次のコマンドを一度だけ実行してください:

xattr -d com.apple.quarantine "/Applications/KeepMeTube.app"
