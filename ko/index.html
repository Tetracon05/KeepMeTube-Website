어느 모드든 완벽합니다.

KeepMeTube는 시스템 테마를 자동으로 따르며, 직접 라이트 또는 다크 모드로 고정할 수도 있습니다. 핸들을 드래그해 두 모드를 비교해 보세요.

다운로드 대기열

모든 다운로드의 진행률, 전송 속도, 기록을 최신순으로 한눈에 — 목록을 필터링하거나, 실패한 항목을 재시도하거나, 재생목록의 대기열을 살펴보세요.

라이트 다크

다운로드 추가

해상도와 컨테이너를 선택한 뒤, 연령 제한 또는 멤버 전용 콘텐츠를 위한 쿠키를 첨부하세요. 링크를 하나 또는 여러 개 붙여넣을 수 있으며, 클립보드에서 자동으로 채워지기도 합니다.

라이트 다크

터키어로 표시되었습니다 — KeepMeTube에 내장된 10개 언어 중 하나입니다.

재생목록도 한 번에

재생목록 링크를 붙여넣으면 KeepMeTube가 이를 분석해, 원하는 영상만 정확히 골라 한꺼번에 대기열에 추가할 수 있습니다. 각 재생목록은 다운로드 목록에서 하나의 행으로 묶이며 — 대기 중인 항목을 볼 수 있는 세부 보기가 함께 제공되고 — 재생목록 이름을 딴 전용 하위 폴더에 저장됩니다.

그저 잘 작동하도록 설계됨

터미널을 건드릴 필요 없이 yt-dlp가 할 수 있는 모든 것.

  • 1,800개 이상의 사이트

    유튜브, 인스타그램, 틱톡, 트위치, 트위터/X, 레딧, 페이스북, Vimeo, 사운드클라우드, 그리고 yt-dlp가 지원하는 거의 모든 곳.

  • 항상 최신 상태

    실행 시 yt-dlp 업데이트를 확인하고 클릭 한 번으로 업그레이드하여, 새로운 사이트와 형식이 계속 작동하도록 합니다.

  • 쿠키 인증

    cookies.txt 파일을 첨부하면 자신의 로그인 세션을 이용해 연령 제한, 멤버 전용, 비공개 콘텐츠를 가져올 수 있습니다.

  • 10개 언어 지원

    English, Türkçe, Español, Français, Deutsch, Português, العربية, 日本語, 한국어, 中文 — 나중에 덧붙인 것이 아니라 처음부터 내장되어 있습니다.

  • 라이트, 다크, 또는 시스템

    OS에 자동으로 맞추거나 직접 설정할 수 있습니다 — 바로 위에서 직접 확인해 보세요.

  • 실시간 진행 상황

    모든 다운로드의 정확한 퍼센트, 전송 속도, 상태가 실시간으로 업데이트됩니다.

  • 스마트 대기열

    다운로드는 설정한 한도까지 자동으로 실행되며, 나머지는 순서를 기다립니다.

  • 사라지지 않는 기록

    다운로드 목록은 재시작해도 유지됩니다 — 앱을 종료해도 아무것도 사라지지 않습니다.

  • 파일 작업 내장

    앱을 벗어나지 않고도 완료된 다운로드의 이름 변경, Finder/탐색기에서 표시, 삭제가 가능합니다.

  • 재생목록을 한 번에

    재생목록 링크를 붙여넣고 원하는 영상만 골라 한꺼번에 대기열에 추가하세요 — 하나의 행으로 묶이고, 전용 하위 폴더에 저장됩니다.

  • 붙여넣기만 하면 끝

    여러 링크를 한 번에 대기열에 추가하거나, KeepMeTube가 클립보드에서 URL을 자동으로 채우게 하세요.

  • 자막·썸네일·메타데이터

    자막 다운로드, 썸네일 삽입, 제목·아티스트 메타데이터 기록까지 — 모두 다운로드별로 선택 가능합니다.

  • 찾고, 다시 시도하고

    입력하는 동안 긴 다운로드 목록을 필터링하고, 실패한 다운로드는 클릭 한 번으로 재시도하세요.

  • 기본값을 직접 설정

    기본 저장 폴더와 파일 이름 템플릿을 선택하고, 동시에 실행할 다운로드 수를 설정하세요.

macOS에서 앱이 “손상되었다”고 나오나요? 손상된 것이 아닙니다 — KeepMeTube는 아직 Apple 공증(notarization)을 받지 않아, Gatekeeper가 기본적으로 App Store 외부에서 받은 모든 다운로드에 경고를 표시합니다.

앱을 마우스 오른쪽 버튼으로 클릭하고 열기를 선택하거나, 터미널에서 다음을 한 번 실행하세요:

xattr -d com.apple.quarantine "/Applications/KeepMeTube.app"
